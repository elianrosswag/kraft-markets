Install the desk display

Flash the KRAFT market display onto a Cheap Yellow Display (ESP32-2432S028, 2-USB version) straight from this page. No software to install. It takes about a minute.

Step 1 · Flash

  1. Open this page in Chrome or Edge on your Mac (Safari can't talk to USB devices).
  2. Plug the display in with a data USB-C cable. Some cables only charge.
  3. Click the button, choose the port that appears (usually USB Serial or wchusbserial…) and follow the prompts.

This browser can't flash devices. Open the page in Chrome or Edge. Flashing needs a secure page (https).

First install: say yes to "erase". Updates: say no, which keeps your saved Wi-Fi.

Step 2 · First boot

  1. The screen asks "Is this screen black?" If you see a white background, tap the screen. It remembers the answer.
  2. A QR code appears. Scan it with your phone (or join the Wi-Fi network KRAFT-CYD). A setup page opens; if it doesn't, go to 192.168.4.1.
  3. Add your home network. You can add your work network at the same time: for networks that sign in with a username, fill in the Username field too.
  4. Tap Done. From then on the display joins whichever saved network is in range on its own, so there's no setup when you arrive at the office.

If something goes wrong

No port appears. Try another cable or USB port. The board uses a CH340 USB chip; recent macOS versions include its driver.

"Failed to connect". Hold the BOOT button on the back, click Install again, and release it once flashing starts.

The screen flickers when the cable moves. That's the power connection, not the software: the USB socket or cable is briefly dropping power. Use a short, good-quality USB-C cable and keep it still (your printed case will help), or power it from a wall adapter instead of a laptop.

Work Wi-Fi won't connect. Some company networks only allow registered devices or use certificates. The guest network is often the easiest option, and it's worth checking with IT before connecting personal hardware.
